## 写作与维护规则

1. **SD-000 的四节是跨模块合约**：§2 目标、§3 SLO、§7 接口契约、§8 预算分解。DD/X 文档**只能引用，不能自行修改或放宽**。需要变更必须回到 SD-000 走架构评审。
2. **DD 之间只能引用对方的契约（IF-x），不能引用对方的内部小节**。需要引用内部细节说明契约缺失，应先补契约。
3. **同一事实只在一处维护**。SD-000 引用下游时只给编号与一句话结论，不复制内容。
4. **判断内容该放哪**：只有单一模块的 owner 才会改动的内容 → 放 DD；需要非工程角色签字的内容 → 放 X；其余留 SD-000。
5. **IF-3 与 IF-8 是双签契约**，任一方变更须对方签字。
